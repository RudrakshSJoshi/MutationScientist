**One-liner:** *"Give it an EGFR mutation and an inhibitor; MutationScientist fuses the measured data, the Boltz-2 prediction, and our fine-tuned LLM's reasoning into one report — and it never shows a guess as a fact."*

**Integration status at demo time**
- **LLM — LIVE.** Our fine-tuned MutationScientist (Qwen3.5-4B LoRA) is served at `http://localhost:8000/v1`; the Report is generated by **our model**. Badge: **✦ LLM REPORT** (violet).
- **Boltz — MOCK placeholder** until `boltz_predictions.json` lands (badge **⚠ MOCK**, red). Flip live with one env var (see end).

> **The Truth Ladder — say this once, point at the pills:** 🟢 green = **MEASURED** (real, cited) · 🔵 blue = **PREDICTED** (Boltz) · 🟣 violet = **REASONED** (our LLM) · 🔴 red = **PLACEHOLDER** (mock/template). "Green is real, blue is the model, violet is the writing, red is a stand-in." That legend is the product's integrity story.

## Guardrails while presenting
- Mock Boltz values are **placeholders**, not predictions.
- The report is written by **our fine-tuned model** (badge ✦); if the server is down it degrades to the grounded **template** (badge ⚠, red) and says so — never silently.
- Keep **biochemical IC50 ≠ cellular ≠ clinical**, and **IC50 ≠ KD ≠ Ki**.
- Score convention, shown on every prediction surface: **affinity = log10(IC50 µM), lower = stronger, NOT pIC50** (1 nM→−3, 1 µM→0).

## Going live with Boltz (if it lands mid-event — no UI change)
